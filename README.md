# Carvalho Music

Página estática pronta para GitHub Pages. A logo está incorporada no HTML; não exige instalação ou compilação. WhatsApp: +55 (11) 98344-1270.

## Publicar

1. Extraia este ZIP.
2. Crie um repositório no GitHub (público para usar Pages no plano gratuito).
3. Clique em Add file > Upload files e envie index.html e README.md na raiz do repositório. Não envie o ZIP.
4. Confirme o envio em Commit changes.
5. Abra Settings > Pages. Em Build and deployment, escolha Deploy from a branch.
6. Selecione a branch main e a pasta / (root). Clique em Save.
7. Aguarde a publicação. O endereço aparecerá nessa mesma tela.

## Editar

Edite index.html. O número está na constante WHATSAPP_NUMBER, no final do arquivo. As mensagens são personalizadas conforme o instrumento.
